# Paradox of the Active User

**Newer · ADVISORY — not scored · owner: Interaction**

- **Definition / why it matters:** Users don't read manuals — they start immediately. Design for
  learning by doing.
- **Why partial/advisory:** the static proxy (inline help, empty-state guidance, sensible
  defaults, no forced upfront tutorial wall) is weak and behavioral. Keep as advisory.
- **How to handle:** advisory note; if a **blocking onboarding wall** before first action is
  detected, call it out as a concrete recommendation.
