# Working Memory

**Newer · weight 2 · tier b · SCORED · owner: IA**

- **Definition / why it matters:** A limited system that briefly holds info needed for a task.
  Don't force users to carry information across steps. Composite with **Miller's + Chunking**.
- **Applies when:** multi-step flows or tasks that reference earlier input.
- **Adherence signals:** context carried forward (a summary/review step; previously entered
  values shown); no re-entry of known data; visible instructions kept on screen while needed.
- **Violation signals:** later steps require remembering earlier values with no on-screen recap;
  instructions shown then hidden before the user acts; re-asking for known data.
- **Confidence:** b.
- **Example fix:** add a review/summary step; keep the relevant instruction visible; pre-fill
  known values.
