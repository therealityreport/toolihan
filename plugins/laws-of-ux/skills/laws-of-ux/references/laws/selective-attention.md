# Selective Attention

**Newer · weight 2 · tier b · SCORED · owner: Visual**

- **Definition / why it matters:** People filter out anything that looks irrelevant — including
  important info that resembles ads ("banner blindness").
- **Applies when:** the UI places important info/CTAs that could be ignored.
- **Adherence signals:** critical info in the main content flow, not ad-like banners; primary
  CTAs not styled like dismissible promos; important content not confined to a right rail.
- **Violation signals:** critical CTAs styled as promo banners; key info in commonly ignored
  regions; ad-like components near important content. Better measured live (layout), so a
  static proxy only.
- **Confidence:** b (static proxy) → a with `--url` layout coords.
- **Example fix:** move a key CTA into the main flow; de-bannerize important messaging.
