# Cognitive Load

**Newer · weight 3 · tier b · SCORED · owner: Forms**

- **Definition / why it matters:** The mental effort to use an interface. Excess load —
  clutter, jargon, too many simultaneous decisions — degrades everything. Treat as a
  **composite/derived** signal of Hick's + Miller's + Occam proxies.
- **Applies when:** essentially always for an interactive UI.
- **Adherence signals:** low element density; plain labels (not jargon); one primary decision
  per screen; inline help; sensible defaults.
- **Violation signals:** dense screens with many simultaneous primary actions; unexplained
  jargon in labels; long forms with no guidance; multiple competing focal points.
- **Confidence:** b (aggregate of the underlying checks).
- **Example fix:** reduce simultaneous choices; add inline help; defer non-essential fields;
  plain-language labels.
