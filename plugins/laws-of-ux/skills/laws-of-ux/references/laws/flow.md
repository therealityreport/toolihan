# Flow

**Newer · weight 1 · tier c · SCORED · owner: Interaction**

- **Definition / why it matters:** A state of full, energized immersion. Interruptions break it.
- **Applies when:** there are focused task flows.
- **Adherence signals (partial):** uninterrupted flows — no gratuitous modals/popups mid-task;
  autosave; minimal context switches.
- **Violation signals (partial):** interrupting modals/popups/interstitials mid-task; forced
  context switches. Grep modal/dialog/interstitial usage inside task flows.
- **Confidence:** **c** — flow is a temporal/behavioral state; mostly advisory/needs-live.
  Report the interruption proxy; mark the state judgment NOT_ASSESSED without `--url`.
- **Example fix:** remove a mid-task interrupting modal; autosave instead of blocking.
