01 - WHAT PEOPLE KEEP SAYING

The conversation is about trust, not novelty

Plugin users are less impressed by long feature lists than by whether a tool says what it touched, where evidence came from, and what failed.

+

Visible evidence wins

Users respond well when plugins leave a concrete artifact, screenshot, or report they can open later.

PRAISE
!

Install drift hurts trust

Broken marketplace paths and stale cache copies create the most damaging confusion because the visible plugin may not match the edited source.

PAIN

Source coverage needs labels

People ask for Reddit, X, GitHub, and web evidence, but they also need clear labels when a source is snippet-limited or unavailable.
